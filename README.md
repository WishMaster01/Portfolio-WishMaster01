# 🚀 Getting Started

## Clone

```bash
git clone https://github.com/WishMaster01/wishmaster01-portfolio.git
cd wishmaster01-portfolio
```

## Install

```bash
npm install
```

## Configure Environment

```bash
cp .env.example .env
```

Update all required environment variables.

---

## Prisma

Generate Client

```bash
npx prisma generate
```

Apply Migrations

```bash
npx prisma migrate dev
```

Seed Database

```bash
npx prisma db seed
```

---

## Development

```bash
npm run dev
```

Open

```
http://localhost:3000
```
